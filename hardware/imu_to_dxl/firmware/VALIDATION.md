# 固件验证记录

对象：imu_to_dxl 0.1.0，STM32G031F8P6 + LSM6DSV16X。
随工程提供的预编译产物用于 J-Link 裸板姿态台架验证；本页区分桌面测试与真实硬件结果。

## 预编译基线（2026-09-15）

| 项目 | 结果 |
|---|---|
| Keil µVision 5.43.1 + Arm Compiler 6.24 重建 | 0错误，0警告 |
| `Tools/build.ps1` CLI构建 | 成功；随工程 BIN/HEX 来自此入口 |
| Flash | 11,612 / 65,536 字节 |
| RAM，包括2KiB栈 | 5,096 / 8,192 字节 |
| 静态数据 | 3,048 字节 |
| 初始栈指针 | `0x20002000` |
| SysTick / USART1 / USART2 向量 | 有效 Flash Thumb 入口 |

本目录保留对应源码及一个 `Build/imu_to_dxl.hex`。从 HEX 解码 `0x08000000` 起的11,612字节
Flash 镜像，其 SHA-256（与原 BIN 相同）：

`69bdaea7224900addd6eb5bd28001e26e07073c129383d9c1ece380d2bfce19a`

原 MAP 审核得到 `sample=0x20000064`、大小60字节；`tick=0x20000BE0`、大小4字节。
这份布局只适用于上述镜像。`tools/servo-web` 的 J-Link 观察器从 HEX 得到 Flash 基线并严格校验，
不依赖已提交的 BIN/MAP，也不接受任意重新编译产物。
开发时仍可生成 `.axf` 断点调试，并用本地 `.map` 核对符号；修改固件后应重新审核读取布局和校验值。

## 原开发板验证（2026-09-20）

- J-Link 100kHz SWD 连接、固件烧录及读回校验通过；Keil 可停在 `main`。
- 64MHz 系统时钟和 IMU 采样已验证；WHO_AM_I=`0x70`、ready=1、SPI/FIFO 错误计数为0。
- 浏览器可通过 J-Link 读取真实姿态，约20Hz刷新。参考电压约3.29V；这不是输入电流、纹波或温升测量。
- 已观察到 J-Link 9.78 建连会重启板上程序；网页归零仅改变显示参考，不写入校准参数。

以上结果仅属于原开发板，其他板卡仍需自己的接线与首次上电检查。

## 尚未完成的验收

- 外部单线半双工总线与舵机尚未实测：USART波特率误差、DE释放时序、电平、共线抗干扰和最坏应答延迟均需现场验证。
- 当前代码实现 Dynamixel Protocol 2.0、ID200、124地址的12字节读取块；未实现最新[总线协议](../总线协议.md)中地址56的15字节飞特协议契约，也未验收 `tools/imu200` 互通。
- 安装坐标、温漂、SFLP长期收敛、栈高水位、看门狗恢复及长期稳定性仍需专门测试。
- 正式运动前，主控需读取诊断状态并处理数据过期；单板返回全零姿态不等于整机已经具有自动停车能力。

本次发布不更改固件协议，也不声称已经完成整机站立、运动或飞特总线验收。
